# Changelog

User-facing release history for Price Helper for iHerb.

## 1.0.0
- Greatly improved product matching for countable supplement formats including softgels, coated tablets, caplets, chewables and similar products.
- Added category price range summary on listing and search pages.
- Added a badge text size preference.

## 0.3.6.1

- Price Helper product badges continue to display when using the browser back button.
- Products in the iHerb Live section are excluded from price calculations.
- Debug mode is off for the beta release.
- The beta flag moved out of `config.json` and into the extension code.

## 0.3.5.1

- Initial release for privately hosted beta at mklimp.com/phiherb
